# Дай пять!

Прикол для приложения СберKids. Двое детей трясут телефоны рядом, телефоны находят друг друга по Bluetooth, и на обоих экранах одновременно играет общий эффект: смесь их стихий. Новая комбинация попадает в альбом.

Сервера нет. По воздуху передаются только 8 байт: стихия, номер готовой аватарки и случайные числа. Ни имён, ни идентификаторов, ни денег.

## Что умеет

- **Соло.** Тряхнул телефон, и поверх экрана вспыхивает твоя стихия.
- **Дай пять.** Двое трясут рядом и получают общую карточку: 6 стихий дают 21 комбинацию.
- **Альбом.** Собранные карточки, силуэты ещё не найденных и кнопка «Поделиться» (картинка без ссылок).
- **Рамки аватара.** Собрал все 6 карточек своей стихии, и вокруг аватара появляется рамка.
- **Подсказка.** При первом входе Главный подсказывает: «Тряхни телефон!».
- **Конфиг без релиза.** Тексты, стихии, комбинации, сезоны и пороги меняются через JSON.
- **Безопасность.** На денежных экранах («Скинуть денег») прикол не работает, эффект не мешает нажатиям.

## Как запустить

Нужны Android Studio и телефон на Android 8 или новее. Для «Дай пять» нужны два телефона.

```bash
./gradlew :app:installDebug
```

Порядок проверки:

1. Тряхни телефон на Главном и выбери стихию.
2. Тряхни ещё раз и разреши Bluetooth.
3. Поднеси телефоны почти вплотную и трясите одновременно. Между попытками делайте паузу 5 секунд.

**Служебный экран** открывается пятью быстрыми тапами по лапке в нижнем меню. На нём видно, кто рядом и с каким сигналом, версию конфига и кнопку «Обновить конфиг». Там же можно показать «Дай пять» без второго телефона.

## Как устроено

| Модуль | Что внутри |
|---|---|
| `prank` | Точка входа: фасад `Prank`, слой поверх экранов, рамка аватара, подсказка |
| `domain` | Чистый Kotlin: модели, правила, протокол и машина состояний рукопожатия |
| `data` | Конфиг, хранилища, датчик тряски, Bluetooth, нужные разрешения |
| `core` | Контроллер прикола, частицы, иллюстрации, общие компоненты |
| `feature/*` | Эффекты, выбор стихии, альбом, служебный экран |
| `app` | Оболочка СберKids, к приколу подключена только через `prank` |

Доменный слой не зависит от Android, поэтому правила и протокол покрыты обычными юнит-тестами.

### Конфиг

Конфиг лежит по ключу CMS `kids_prank_high_five`. В прототипе это файл [`config/kids_prank_high_five.json`](config/kids_prank_high_five.json), приложение скачивает его с GitHub. Копия встроена в сборку, поэтому без сети прикол тоже работает. Битый или пустой конфиг выключает прикол, а приложение продолжает работать.

Чтобы выкатить изменения без релиза:

1. Поправь JSON, например даты сезона в `seasons`.
2. Увеличь `version`.
3. Запушь в `main` и нажми «Обновить конфиг» на служебном экране.

## Протокол Bluetooth

Данные спрятаны в 128-битном UUID рекламного пакета. Первые 8 байт занимает префикс приложения (`hif5kids`), в следующих 8 байтах лежат данные:

| Байт | Поле | Значение |
|---|---|---|
| 1 | `ver` | Версия протокола, сейчас 1 |
| 2 | `phase` | 0: HELLO, 1: CONFIRM |
| 3 | `el` | Стихия, 1–6 |
| 4 | `ava` | Номер готовой аватарки, своё фото передаётся как 0 |
| 5–6 | `nonce` | Случайное число, новое на каждую тряску |
| 7–8 | `peer` | Чужой `nonce` в подтверждении, в HELLO он равен 0 |

Как проходит рукопожатие:

1. После тряски телефон 3 секунды вещает HELLO и слушает эфир.
2. Увидел соседа достаточно близко (медиана трёх замеров сигнала не ниже порога) и отвечает CONFIRM с его `nonce`.
3. Друг засчитывается, только если он тоже прислал CONFIRM с твоим `nonce`.
4. Эффект играет сразу, а телефон ещё 1,5 секунды подтверждает другу, чтобы тот тоже успел.

Логика рукопожатия написана как чистая функция `reduce(state, event)` в `domain`, поэтому её можно проверить без телефонов. Протокол одинаково реализуется на iOS: там данные тоже передаются в UUID сервиса.

## Как встроить в СберKids

Нужны Compose и Hilt. Подключаешь модуль `prank`, остальное он подтянет сам, включая разрешения.

```kotlin
// 1. Application.onCreate: всё необязательно, есть значения по умолчанию
Prank.configure {
    configUrl = "https://cms.example/kids_prank_high_five.json"
    avatarIndex = { profile.avatarIndex }
}

// 2. Корень UI: слой прикола поверх навигации
PrankOverlayHost(currentScreen = screen) { AppNavHost() }

// 3. Входы, где удобно
Prank.openAlbum()
Prank.openElementPicker()
```

По желанию:

- `PrankAvatarFrame { Avatar() }` добавляет рамку вокруг аватара приложения.
- `PrankShakeHint()` показывает подсказку «Тряхни телефон!».
- `Prank.openServiceScreen()` открывает служебный экран.

`currentScreen` подсказывает приколу, где он разрешён: на денежных экранах (`MONEY_TRANSFER`, `QR_PAYMENT`, `CARD_DETAILS`) тряска ничего не делает.

Новых эндпоинтов нет, сетевой запрос один: загрузка конфига.

## Разрешения

- Android 12 и новее: `BLUETOOTH_SCAN`, `BLUETOOTH_ADVERTISE`, `BLUETOOTH_CONNECT`.
- Android 8–11: Bluetooth и геолокация (`ACCESS_FINE_LOCATION`), это требование системы для поиска устройств.

Разрешения запрашиваются только по действию ребёнка. Без них прикол работает в режиме соло.
